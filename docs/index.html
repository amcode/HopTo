Hop To
How it works GitHub

Press ⌥ Space, type a bit, press Return.

A tiny, free Mac launcher that opens apps and System Settings panes. It doesn't do anything else, which is why it's quick.

    Download for Mac
    macOS 13 or later · free and open source · no permissions needed

    Finds what you meant

    Prefixes, acronyms and typos-in-the-middle all work: saf, vsc, am, trmnl.

    Settings, by the words you'd say

    wifi, dark mode, bluetooth, input monitoring — straight to the right pane.

    Learns your habits, gently

    What you open often floats up. It never beats a clear match, so saf is always Safari.

    Keyboard all the way

    Arrows, Return, Esc, and ⌘1–⌘9 to jump straight to a row.

    What it doesn't do

    No clipboard history, workflows, snippets, file search, calculator, web search, plugins or accounts. No network access at all. If you want those, the big launchers are excellent — Hop To is for when you only ever used the first feature.

    How it works

    ⌥ SpaceOpen or close the panel. Swap for ⌃ Space, ⌘⌥ Space, ⌘⇧ Space or ⌃⌥ Space from the menu bar.
    ↑ ↓Move the selection.
    ReturnOpen it.
    ⌘1–⌘9Open that row directly.
    EscClose.

    Apps are found by scanning the usual folders (and any you add). Settings panes come from a built-in list plus whatever your macOS version has. The shortcut is registered with the system directly, so there's no Accessibility or Input Monitoring prompt. The code is open for you to check.
